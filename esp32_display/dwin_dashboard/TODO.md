## 二、已定案的決策

| 項目 | 決定 | 理由 |
|---|---|---|
| 架構 | 手機取資料 → ESP32 → 螢幕 | 不移除手機（移除方案已評估，暫不採用） |
| 電源 | 車上 12V（ACC）直供螢幕，ESP32 經 DC-DC 取 5V | 油電車的 12V 由 LDC 穩壓，無發動壓降 |
| 通訊協定 | 沿用現有 `esp32_dash` JSON | 手機端一行都不用改 |
| MCU | **ESP32-C3 / S3 即可** | DGUS 接手渲染後不需要 MIPI/PSRAM；OBD 由手機負責，**不需要 BT Classic** |
| UI 產出分工 | `14/13/22/CFG` 在 Mac 產生；`.ICL` 需 Windows | ICL 格式未公開，只能用 DWIN 工具 |
| 字型 | 螢幕端不需要字型檔 | 中文靜態畫進背景；動態值全是數字，用內建 0# ASCII |
| 中央版面 | 垂直堆疊（時速 / 轉速 / 增壓） | 圓形與拱形都與方正卡片不協調 |
| 數值對齊 | 以標稱位數（時速兩位、轉速四位）置中，單位固定 | 單位是靜態的不能動 |

## 三、採購清單

**必要**
- ESP32-C3 / S3 開發板（只需 WiFi；OBD 由手機負責，不需要 BT Classic）
- DC-DC 降壓 12V→5V，1A 以上，**開關式**（不要用 AMS1117 線性穩壓吃 12V）
- MicroSD 卡 **16GB 以下**（要能格式化成 4KB 磁區的 FAT32）
- 保險絲座 + 2~3A 保險絲、ACC 取電線、杜邦線
- **三用電表** —— 接線前量 `TX2` 靜態電壓確認 TTL/RS232（接錯會燒 GPIO）
- 2.54mm 排針（若 `CN3` 未預焊，需確認）

**可能不需要**
- MAX3232：出廠預設為 TTL，量測確認後多半用不到
- 緩衝電容：油電車無發動壓降，不需要

**其他**
- 螢幕固定支架 / 3M 膠（裸板無外殼），**背面留通風**

## 四、採購前要問經銷商

- [ ] **儲存溫度**（工作溫度是 −20~70°C，但停車曝曬屬儲存條件，規格書沒列）
- [ ] **是否有硬體 RTC、有無電池備援**（`RTC_Set 0x009C` 註明 "Need hardware RTC support"）
- [ ] **TTL 電平是 3.3V 還是 5V**（ASIC 是 3.3V IO，但模組上是否有轉換未知）
- [ ] `CN3`（6P/2.54mm）**有沒有預焊排針**、盒裝附不附線材
- [ ] 色域 / 對比度（產品頁未公布，非必要）
- [ ] 這個尺寸有沒有 **`Q` 車規版**（目前是 `C` 商規）

## 五、機種選擇（待定）

| | DMG12480C068_03WTC | DMG12400C074_03W |
|---|---|---|
| 尺寸 / 解析度 | 6.8"、1280×480 | 7.4"、1280×400 |
| **亮度** | 250 nit | **650~700 nit** |
| 功耗 | 2.4 W | 4.5 W |
| 喇叭 | — | 內建 2W |

**建議 7.4"** —— 亮度是車用的決定性差異（手機 Reno 4Z 是 480 nit，6.8" 只有一半）。
垂直少 80px 已驗證版面撐得住（`assets/preview_400.png`）。
7.4" 可以用 50% 亮度達到 ~325 nit，發熱反而比 6.8" 全亮更低。

## 六、硬體到貨後的順序

### 階段 1：通電與接線
- [ ] **先只給螢幕上電，量 `TX2` 對 GND 的靜態電壓**
      → +3.3V 表示 TTL，可直接接 ESP32
      → −5~−12V 表示 RS232，**直接接會燒掉 ESP32 GPIO**
- [ ] 12V 直供螢幕；ESP32 由同一組 12V 經 DC-DC 降壓取 5V；GND 共接
- [ ] 取 **ACC** 電，不要接常電（停車後螢幕會一直亮著烤自己）
- [ ] 接 `CN3`：ESP32 TX → RX2、ESP32 RX → TX2
- [ ] 先用 DGUS 原廠範例確認螢幕會動

### 階段 2：UI 素材
- [ ] 版面定案（含下方「未決的版面問題」）
- [ ] `gen_background.py` 產生 `background.png` / `icon_ev.png`
- [ ] **`.ICL` 轉檔**（Windows / Wine / 借電腦）← **唯一沒有替代方案的環節**
- [ ] 寫 `14.BIN` 產生器（顯示控制項，位元組格式見開發指南 §7）
- [ ] 寫 `13.BIN`（觸控）、`22.BIN`（初值）、`T5LCFG.CFG`
      - CFG `0x06` bit7 = 1（啟用 PWM 背光控制，否則亮度指令無效）
      - CFG `0x05` bit4 = 1（觸控自動上傳，否則按鈕不會回傳）
- [ ] SD 卡（FAT32、4KB 磁區）放 `DWIN_SET/` 載入

### 階段 3：ESP32 韌體
- [ ] 沿用現有的 WiFi + WebSocket Server + ArduinoJson
- [ ] JSON → VP 寫入（`5A A5 05 82 <VP> <值>`）
- [ ] 補間：沿用 `anim_ms()` 的概念（依實測間隔決定），改成每 20ms 寫 VP
      （DGUS 週期固定 20ms = 50Hz；UART 上限每週期 4KB，我們只用約 240B）
- [ ] 亮度 → `LED_Config (0x0082)`，級距 0~100 與手機端設定 1:1
- [ ] 觸控回傳解析（`5A A5 <len> 83 <VP> <len> <data>`）
- [ ] 時鐘改用螢幕 RTC（`0x009C`），手機偶爾校時即可

### 階段 4：手機端調整
- [ ] **ESP32 儀表啟用時停用螢幕常亮**（`WakelockPlus`）——
      手機藏起來後螢幕常亮既沒意義又是主要發熱源。**需保留開關可切回**
- [ ] 日間亮度預設由 100% 調低（發熱直接下降）
- [ ] 停車後（資料逾時 N 分鐘）自動把亮度寫 0

| 風險 | 說明 |
|---|---|
| **ICL 轉檔** | 格式未公開，社群專案明確表示無法產生新檔。**這關過不去整條路線不成立** |
| 迭代方式改變 | 改背景美術要重跑 ICL + 換 SD 卡；但改數值位置/顏色只動 `14.BIN`，純 Mac 作業 |
| 停車曝曬 | 台灣夏天車內可達 60~80°C，超過 70°C 工作上限。靠安裝位置 + 降亮度 + 停車關背光 |

## 十、暫不採用（已評估，保留紀錄）

- **完全移除手機、全部交給 ESP32**：技術可行（資料 3.16MB CSV 轉二進位僅約 200KB；
  語音可用 DWIN 內建喇叭播預錄 `.WAE`），但需把 11 個 Dart service 重寫成 C、
  失去螢幕錄影與 MQTT 後送、且會失去現有的除錯工具。
  若日後要走，建議分階段（GPS → 測速/速限 → 語音 → OBD），每步可驗證可回退。
- **用 T5L 的 OS 核心取代 ESP32**：8051 僅約 28KB 程式空間、無網路堆疊，
  要 WiFi 仍得外掛 ESP 模組，等於把現成的函式庫改成手刻。不划算。
- **螢幕自動亮度**：模組無光感測器，且連接器未拉出 ADC 腳位。
  現有的「依大燈狀態切換」在車上反而比光感測器可靠（不會被隧道/樹蔭誤觸發）。

- **改用大彩 DC12480DH068（DH 系列 6.8" 1280×480）**：硬體明顯較強
  —— 64-bit 600MHz SOC + DDR、JPEG/PNG 硬解、**向量字型**（不必再產生點陣
  字型，可省掉我們踩過的缺字/方框問題）、**LUA 腳本**、可選 WiFi / CAN。

  **LUA API 足以完全取代 ESP32**（已查證官方文件）：
  `on_server_recv_data()` 讓螢幕自己當 TCP Server、`set_backlight(0~100)`
  級距與現有亮度設定相同、`set_fore_color()` 可執行期改色（紅字警示）、
  `set_visiable()` 切換顯示（EV / 測速照相）、`start_timer()`/`on_timer()`
  做補間、`on_systick()` 每秒驅動時鐘、`set_wifi_cfg()` 做設定頁。
  架構可由「手機→ESP32→螢幕」簡化為「手機→螢幕」。

  **排除的理由**：
  1. 專案格式**完全沒有公開文件**，也無社群逆向 —— 我在 Mac 上
     **一個檔案都產不出來**。DWIN 至少 `14/13/22/CFG` 的位元組格式是公開的，
     我們反覆調整的「數值位置/字級/顏色」全在那半邊，可留在 Mac 版控
  2. 手機端第二通道要從 WebSocket 改成裸 TCP（LUA 拿到的是位元組陣列，
     在 LUA 手刻 WebSocket 握手與 SHA-1 不划算）
  3. 官方文件未確認標準 LUA 字串庫可用，JSON 解析有風險
     （可用定長二進位框繞開，但增加不確定性）
  4. **沒有藍牙** —— 日後若要走「完全不用手機」，ESP32 還是得裝回來
  5. 亮度、工作/儲存溫度、供電電壓產品頁均未公布

  參考：[LUA API](https://doc.gz-dc.com/LUA/000_lua%20api.html)、
  [DH 系列發布](https://www.gz-dc.com/article/id/7263.html)
